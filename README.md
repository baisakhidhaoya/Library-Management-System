# 📚 Library Management System

A simple console-based Library Management System developed using Python.

This project allows users to manage books, search for books, issue and return books, and maintain library records using a JSON file.

## 🚀 Features

- Add new books
- View all books
- Search books by title or author
- Issue books to students
- Return books
- Remove available books
- Automatically save library data
- JSON-based data storage
- Simple command-line interface

## 🛠️ Technologies Used

- Python
- JSON
- File Handling
